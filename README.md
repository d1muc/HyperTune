HyprTune is a PyQt6-based graphical configuration tool for managing monitor display settings and real-time color correction via GLSL shaders in the Hyprland window manager. It provides features for shader-based color correction to adjust brightness, contrast, exposure, gamma, shadows, midtones, highlights, saturation, vibrance, hue, temperature, tint, and individual RGB channel gains in real-time. The application includes presets management for quickly switching between built-in and custom image presets, display control for configuring monitors, resolutions, refresh rates, and scaling parameters directly through the GUI, hotkeys integration to seamlessly bind shortcuts for toggling shaders and updating display profiles via Hyprland, and clean, customizable UI themes matching modern desktop rice aesthetics.
